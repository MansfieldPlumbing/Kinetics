# Math kinetic upgrade pack

These replace the four literal/metaphor-heavy named examples with algebra-first staging.

## 01-hidden-variable-extraction.html
Use around VTT nodes 4–10 (hidden number / variable / mystery / isolate the letter).
Primitives reused: repeated-text perspective depth, camera/zoom language, character-index ramp, spring/additive trail, magnetic snap.

## 02-balance-mirror-operation.html
Use around nodes 10–18 and again 29–37 (whatever you do to the left / do it to the right / balance / golden rule).
The `=` sign is the invariant axis. One operation flies in, splits at equality, and strikes both sides symmetrically. No seesaw.

## 03-equation-cancel-transform.html
Use around nodes 19–25 (`X + 4 = 10`, subtract four, `X = 6`).
Terms are separate objects. `−4` is applied to both sides, `+4` and `−4` visibly cancel, `10−4` computes, and the surviving terms snap into `X = 6`.

## 04-reverse-order-layer-unwrapping.html
Use around nodes 38–50 (two steps / backwards order / peel layer by layer / `2X−5=15`).
Uses nested transform wrappers instead of literal onion rings. Remove `−5` first with `+5`, then remove `×2` with `÷2`, then camera-lock the solved `X = 10`.

## Design rule
Animate *equation state*, not a cartoon metaphor for the lyric. Metaphor can influence motion vocabulary, but the visible objects should usually be the actual terms/operators/variables.
